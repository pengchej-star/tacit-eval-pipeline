
## Memory
The folder `memory/` documents the knowledge of expert machine-learning practitioners who improved solutions of Kaggle competitions:
- `memory/taxonomy.md` is a tree of the decisions one can face when improving a solution (the options under each decision and what is worth knowing before choosing).
- `memory/attention/` has one file per decision of that tree: what the experts looked at before choosing, in what order, how much evidence was enough, and when they came back to the decision.

Read `memory/taxonomy.md` first and open the `memory/attention/` files that match your situation. Treat them as prior experience, not as instructions: use an entry only when it matches this solution, and check it against what the code and the history show. Do not modify the files in `memory/`.
