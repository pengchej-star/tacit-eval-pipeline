v017 reverts v016's tweaked normalization mean back to the ImageNet values ([0.485, 0.456, 0.406]), because that change dropped the LB score from 0.9606 to 0.9522. The main change: instead of the single fold-4 checkpoint, the script now ensembles all 5 fold ResNet200D checkpoints from the attached dataset, each with horizontal-flip TTA. That should be the biggest gain for macro AUC. Weights now load with strict=True, which confirms every checkpoint matches the model. Inference runs under AMP with batch size 64 so it fits in time and memory (about 2 minutes for the full test set). The meaningless ×50 output scaling is dropped, since AUC only depends on rank.
