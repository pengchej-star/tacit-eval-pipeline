v039 keeps v038's features and its LR→RF pipeline as they are, but changes how the RF output becomes probabilities. v038 hard-assigns each sample to a cluster and outputs that cluster's tamed center. v039 instead uses a "soft" assignment: the RF `predict_proba` vector is sharpened by a power, used to take a weighted average of the k-means cluster centers, and then tamed toward the mean training probabilities. The power and tame fraction are scanned on the validation set, the same way the expert tunes `tamefac`, and the soft output is used only if it beats the hard-assigned tamed KL. This suits a KL metric, which heavily penalizes confident wrong cluster picks. Locally, validation KL dropped from 1.075 (hard, v038) to 0.922 (soft: power=2.0, frac=0.95), though that number is somewhat optimistic because the two parameters were tuned on the same validation set.
