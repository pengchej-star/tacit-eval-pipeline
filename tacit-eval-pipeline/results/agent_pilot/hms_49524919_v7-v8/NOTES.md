v008 keeps v007's inference pipeline (log-clipped spectrograms, instance normalization, no TTA) and swaps the single model set (v1.2) for an ensemble of all four 5-fold model sets in the dataset: efficientnetv2_spectrogram, v1.1, v1.2 and v1.3. That is 20 models, with logits averaged before the softmax as before. The v007 code already looped over `enumerate([models])` for this purpose. Averaging the out-of-fold predictions the training runs saved puts OOF KL at 0.635 for all four sets, against 0.741 for the best single set and 0.664 for the best pair, so this is the biggest gain available without retraining.
I also cache predictions per spectrogram_id, since rows that share a spectrogram get identical predictions, and I added an fp32 fallback for when an fp16 forward pass returns non-finite logits. One model (v1.1, fold 5) gave NaN on a saturated test spectrogram, which would otherwise have put NaNs in the submission.
