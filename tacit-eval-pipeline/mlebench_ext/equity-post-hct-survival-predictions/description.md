# CIBMTR - Equity in post-HCT Survival Predictions

## Overview

Improve the prediction of transplant survival rates for patients undergoing allogeneic Hematopoietic Cell
Transplantation (HCT). Survival predictions are important for patient care and resource allocation, but
current models can be biased by socioeconomic status, race and geography. The goal is a model that is both
accurate and fair across diverse patient groups. The data are synthetic, generated by the CIBMTR (Center for
International Blood and Marrow Transplant Research) to mirror real-world patient characteristics while
protecting privacy.

## Evaluation

Submissions are evaluated with a stratified concordance index (C-index). For each `race_group`, the C-index
between the observed event-free survival times (`efs_time`, censored by `efs`) and the submitted risk score is
computed. The final score is the mean of the per-group C-index values minus their standard deviation, which
rewards models that are accurate in every group.

`prediction` is a risk score: a higher value means the event is expected sooner (shorter event-free
survival). A constant prediction scores 0.5. Higher is better.

## Submission File

For each `ID` in the test set, predict a risk score. The file must contain a header and have the following
format:

```
ID,prediction
28800,0.5
28801,0.5
28802,0.5
etc.
```

## Data

- `train.csv` - the training set; the target is `efs` (1 = event, 0 = censored) together with `efs_time`
  (time to event or censoring, in months)
- `test.csv` - the test set; same columns as `train.csv` without `efs` and `efs_time`
- `sample_submission.csv` - a sample submission file in the correct format
- `data_dictionary.csv` - description of every feature, its type and its values

Note on this version of the data: the test set is a random 10% of the original competition's training data
(the original competition's test set is not public), and `train.csv` holds the remaining 90%.
