v014 swaps the RBF-kernel SVC classifier for a Ridge regressor (alpha=1.0) on a richer TF-IDF (word unigrams+bigrams, IDF on, no stop-word removal, min_df=5, max 100k features), and rounds and clips predictions to 1–6. The essay score is ordinal and QWK punishes predictions that are far off, so regression fits the metric better than one-vs-rest classification. On the expert's own 10% holdout (random_state=123), v011's SVC setup scored about 0.708 QWK and the new pipeline scores about 0.745; it also trains in seconds instead of minutes. I also made the regex patterns raw strings and added `regex=True` so the digit-stripping step actually runs, and swapped `display` for `print` so the script runs outside a notebook.
